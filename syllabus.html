Objectives This course aims to provide students with a strong foundation in web development by introducing HTML, CSS, and JavaScript. The course enables students to design structured web pages, create responsive user interfaces, and develop dynamic and interactive web applications. It also focuses on enhancing logical thinking, problem-solving abilities, and programming skills through JavaScript-based programming concepts and real-world web application development.
Expected Outcome After successful completion of this course, students will be able to understand the fundamental concepts of web technologies and front-end web development. They will gain the ability to design and develop structured web pages using HTML, create responsive and visually appealing user interfaces using CSS, and apply JavaScript programming concepts to solve basic programming problems. Students will also be able to develop interactive and dynamic web pages through DOM manipulation and event handling techniques. By integrating HTML, CSS, and JavaScript, they will be capable of building small web applications while enhancing their logical thinking, problem-solving, and debugging skills, thereby establishing a strong foundation for advanced web development technologies.
Unit No. Unit Title No. of Hours(Per unit)
UNIT I Introduction to Web Technologies and HTML 8
Introduction to front-end development, Internet and World Wide Web (WWW), web browsers and web servers, website architecture, structure of an HTML document, HTML5 elements, headings, paragraphs, text formatting tags, hyperlinks, images, lists, tables, forms, multimedia elements (audio and video), iframes, and semantic HTML5 tags
UNIT II CSS Fundamentals and Responsive Web Design 8
Introduction to CSS, types of CSS, CSS selectors, colors, backgrounds, borders, fonts, text properties, CSS box model, margin, padding, display properties, positioning techniques, Flexbox, CSS Grid, media queries, responsive web design principles, transitions, and animations.
UNIT III JavaScript Programming Fundamentals 7
Introduction to JavaScript, syntax, variables, data types, operators, input and output methods, conditional statements, loops, functions, scope of variables, and basic problem-solving techniques.
UNIT IV JavaScript for Interactive Web Development 8
Arrays, strings, objects, DOM manipulation, event handling, form validation, error handling, debugging techniques, and browser storage concepts..
UNIT V Front-End Application Development 8
Timers (setTimeout, setInterval), ES6 concepts, arrow functions, JSON, local storage, session storage, introduction to APIs, and development of simple front-end applications.
